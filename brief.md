12 briefs de sites pour portfolio (sessions cloud Claude Code)
Comment les utiliser
Crée un dépôt GitHub par site (ex. site-obscura), avec un fichier brief.md contenant le brief ci-dessous (bloc COMMUN + bloc du site).
Lance une session cloud par dépôt avec ce prompt :

Lis brief.md et construis le site complet. Respecte la direction artistique à la lettre. Fais plusieurs passes : structure, design, animations, puis relecture (responsive, accessibilité, performance). Commit régulièrement.

Récupère chaque branche, teste dans htdocs (git pull), demande des retouches en local.
BLOC COMMUN (à coller en tête de chaque brief)
Projet fictif de démonstration pour un portfolio de développeur web. Marque et contenus inventés (aucune marque réelle imitée).
Techno : HTML5, CSS3 moderne (variables, grid, clamp, container queries), JavaScript vanilla. Aucun framework, aucune build obligatoire. Doit s'ouvrir en double-cliquant index.html ou depuis XAMPP.
Polices : Google Fonts (2 familles maximum), font-display: swap.
Responsive mobile-first, testé de 360 px à 1920 px.
Accessibilité : contrastes AA, navigation clavier, alt, prefers-reduced-motion respecté, sémantique HTML correcte.
Performance : pas d'image lourde. Visuels générés en SVG, CSS ou canvas, ou placeholders propres. Lighthouse visé : 90+.
Textes réalistes et soignés en français. Zéro "lorem ipsum".
SEO de base : title, meta description, Open Graph, favicon SVG.
Animations : sobres, fluides, au service du concept (IntersectionObserver, CSS, Web Animations API).
Livrer un README.md : concept, choix de design, structure des fichiers, comment lancer.
1. MAISON OBSCURA : restaurant gastronomique « dans le noir »

Concept : un restaurant où l'on dîne dans l'obscurité totale. Le site doit donner la même sensation : on découvre le contenu à la lumière d'une lampe. Pages : accueil, menu dégustation (5 services), l'expérience, réservation (formulaire front), contact. Direction artistique : fond noir profond (
#07060a), halos ambrés (
#ffb347), blanc chaud pour le texte. Serif éditorial élégant en titres (Fraunces ou Cormorant Garamond) + sans-serif discret (Inter). Interaction signature : le curseur (ou le doigt sur mobile) est une torche : un masque radial révèle le contenu autour de lui. Un bouton « Allumer la lumière » bascule vers un mode clair lisible.
